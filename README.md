# Bingo Dog Wash Website

Bingo Dog Wash is a modern self-service dog wash platform that combines professional dog washing stations with online booking, pet products, memberships, and resources for dog owners. Our mission is to make dog care simple, affordable, convenient, and accessible across the United Kingdom.

This repository contains the source code, assets, and documentation for the official Bingo Dog Wash website.
